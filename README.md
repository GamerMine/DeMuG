# DeMuG
GameBoy emulator for Linux, Windows and MacOSX

# Dependencies

## Fedora

`sudo dnf install cmake clang-devel xorg-x11-server-devel libXrandr-devel libXinerama-devel libXcursor-devel libXi-devel glew-devel`
